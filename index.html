03
Deep Learning · Transfer Learning

Plant Disease Detection using CNN (ResNet-50)

Fine-tuned ResNet-50 (ImageNet weights) on the PlantDoc dataset using a two-stage training strategy — first warming up the classification head, then surgically unfreezing the top 50 layers for fine-tuning. Applied aggressive augmentation (rotation, zoom, brightness, vertical flip) to simulate real-world field conditions. Used EarlyStopping, ReduceLROnPlateau, and ModelCheckpoint callbacks for robust training. Evaluated with a full classification report and confusion matrix across all disease classes.
